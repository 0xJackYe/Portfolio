# 开机启动配置

更新日期：2026-10-21。设置在当前 Windows 用户登录桌面后生效。

| 项目 | 设置 |
| --- | --- |
| Google Chrome | 打开期权看板 http://127.0.0.1:8766/#options 和 https://chatgpt.com/ |
| Skyline VPN | 保留原有登录任务，登录后延迟 5 秒打开程序 |
| Steam、飞书、Teams | 关闭开机自启，包括两个注册表视图及 Teams 包启动任务 |

## 这次修复了什么

旧快捷方式指向的脚本目录，在实际登录进程中不存在；实际登录进程读到的 Steam、飞书启动项也仍然存在。仅从之前的执行环境检查目录和注册表，会误以为设置已经生效。这次通过普通用户的实际登录任务执行安装，并从同一环境检查设置和启动结果。

现在使用 WorkStartup - Workspace 当前用户登录任务，延迟 10 秒，以普通用户权限运行。另有 HKCU Run 中的 WorkStartup Workspace 及启动文件夹中的 Work Startup.lnk 作为备用入口。它们共用互斥锁和本次登录标记，避免重复启动服务或重复开网页；任务失败可间隔 1 分钟重试，最多 3 次。

先启动本地服务并在 Chrome 打开期权页，再等待 VPN 与外网连接并打开 ChatGPT。网络等待最多 90 秒，超时仍尝试打开 ChatGPT；不会阻塞本地看板。Chrome 请求失败最多重试 3 次，成功请求不会重复发送。沿用原有 Chrome 用户资料。

Skyline 原有最高权限任务保持不变。这里的设置负责打开 VPN 程序；是否自动连接仍取决于 VPN 本身。

## 恢复原设置

在普通 PowerShell 中执行：

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\Users\yxh\AppData\Local\WorkStartup\restore_startup.ps1" -SkipVpnTask

这会恢复本次修改的应用启动设置和快捷方式，并移除本次创建的看板登录任务和 Run 入口，保留 VPN 任务。原始设置保存在 startup-backup.json、startup-policy-backup.json 和快捷方式备份中；重复安装保留备份。修复过程中临时诊断任务的捕获另存于 startup-policy-task-origin-backup.json，恢复依据为修复前实际没有看板登录任务的状态。

恢复命令不会删除程序、日志或备份。需要撤销原 VPN 任务时，可按原方案在管理员 PowerShell 中单独使用 restore_startup.ps1 -VpnTaskOnly。
