# 欧易只读资产监控

2026-10-24，本地钱包页新增欧易账户模块，地址：http://127.0.0.1:8766/#wallet 。

## 已配置

已从用户提供截图的二维码离线读取 API Key 与 Secret，保存到 Windows 当前用户 DPAPI 密文文件。没有在源代码、日志、浏览器存储中保存明文。截图没有 Passphrase，真实私有账户读取尚待用户在本地页面补充并保存。

## 范围与口径

- 仅固定欧易 HTTPS 域名的白名单 GET，读取交易账户和资金账户；不含赚币、其他子账户。
- 按币种展示交易权益、交易可用、资金余额、资金可用及负债。交易权益不是单纯现货持币数量。
- BTC 净额 = 交易账户 BTC 权益 + 资金账户 BTC 余额，保留负数与精确小数。
- 交易账户 USD 权益使用欧易 totalEq；资金账户无可靠完整 USD 估值时，资金估值和合计显示“—”，不按零处理，也不假定 USDT 永远等值 USD。
- 独立后台工作线程约每 30 秒读取，不阻塞报价、警报或链上钱包。失败保留旧快照并标为缓存。
- 连接后每 5 分钟记录真实 BTC 净额快照，最多约 30 天；凭证和快照均加密保存。不会编造接入前历史，余额变化不直接称为收益。
- API 更换隔离历史和延迟返回；口令错误可单独重新填写 Passphrase，无须再次提供已保存 Key/Secret。

## 测试证据

全站回归 `full-tests/report.json`：1,568 项通过。另在测试发现阶段之后完成的 HTTP 测试 `http-final.log`：15 项通过。合计 1,583 项，通过情况汇总在 `acceptance.json`。

其中新增欧易测试：客户端 39、服务 25、本机 HTTP 15、前端 30，共 109 项。覆盖签名、校时、读取权限、重定向拒绝、超时、负债与小数精度、口令补充、凭据加密、断网缓存、后台非阻塞、旧账户隔离、非法来源与私密文件不可访问。

`secret-scan.json`：扫描 1,005 个文本文件，未发现该 Key/Secret 明文。欧易公开时间接口已实际连通；尚不能在缺少 Passphrase 时宣称真实账户资产验证成功。

## 用户操作

在钱包页“欧易账户”输入创建该 API 时设置的 Passphrase，点击“保存并连接”。不是欧易登录密码。验证成功后显示账户快照；错误会显示安全的原因分类。API Key、Secret、Passphrase 均不会返回给网页。

官方认证和账户文档：https://www.okx.com/docs-v5/en/ 。
