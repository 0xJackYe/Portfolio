# 第二轮深度测试闭环

日期：2026-10-18，北京时间。测试对象为本机 8766 服务、期权独立页及终端内的提醒、期权、钱包模块。

执行流程：以原 973 项回归为基线，补充此前未覆盖的故障与竞态，先复现失败，再修复；各模块做独立复测，合并后执行两轮完整回归，并重新部署、检查真实页面和公开行情。

## 复现并修复

| 范围 | 实际问题与修复 |
| --- | --- |
| 筛选与详情 | 陈旧参考合约切换到期日后仍占据详情。现在详情和列表遵守同一到期日范围，包括跟随期权链和无匹配范围。 |
| 空行情恢复 | 空快照保留旧行时仍携带旧盘口证明。现在撤销当前有效证明，保留原始行的独立副本；重新收到有效行情后恢复。 |
| 数量模式 | 清空手工数量后，切换自动模式会被已禁用字段继续阻塞。现在仅手工模式要求手工数量，自动模式仍按其自身规则校验。 |
| 钱包事务 | 汇总失败后，迟到分页继续请求并覆盖失败状态。整轮刷新现在共用取消域，失败、超时或页面离开时停止剩余任务，保留完整已对账快照，包括汇率。 |
| 设置保存 | 保存期间后台重启或另一窗口更新设置，旧成功响应误清未保存输入。现在检查当前实例与实际提交值，未确认时保留输入并提示检查。 |
| 停机持久化 | 停机等待上限后，迟到声音线程可覆盖新实例设置。已封闭实例不再写旧状态，最后一次持久化在停机受锁区完成。 |
| 数值解析 | 超大数字导致 OverflowError；嵌套 1e999 可变成非有限值，破坏后续 JSON 输出。现在无效数值安全拒绝，严格 JSON 解码覆盖非有限常量与指数溢出。 |
| 现货响应完整性 | 合法 JSON 前缀可能掩盖未收完或超长响应。现在使用完整、有界、有总时限的公开传输读取；WS 字节也要求 UTF-8。 |
| 多合约标记补齐 | 16 个关注合约逐笔补齐受 120 权重/分钟预算限制，离线复现最大字段年龄约 59 秒。较多目标现在共用一次完整公开标记响应，并逐合约校验；缺失目标、重复合约、429 和并发更新仍严格处理。 |
| 重启缓存 | 较新的缓存只要是数组、错误嵌套结构或非有限元数据，就可能阻止启动或破坏 SSE 编码。现在跳过损坏文件并继续查找有效快照，目录缓存也采用同一严格解码。原核验时间不更新。 |

## 复测证据

基线：`baseline/report.json`，973 项通过。

修复后的两轮完整回归分别保存在 `final-cycle-1/report.json`、`final-cycle-2/report.json`：**每轮 1,005 项全部通过**，相对基线新增 32 项。两轮期间没有额外改动生产代码。

新增覆盖来自期权 UI 8 项、终端/钱包 6 项、网络与警报故障注入 9 项、标记恢复容量与异常 6 项、损坏缓存恢复 3 项。缓存测试内另含多种错误结构与非有限数值子场景。每个已修复问题均有修复前的失败复现；独立复测还覆盖关闭重开、隐藏恢复、输入与导出防抖、跨午夜、缺失时间戳、重启去重、HTML 导出后重新执行等组合。

多关注合约的有界模拟采用实际请求预算与实际提交校验，替换时间和网络，运行 180 秒。修复后所有 16 个合约的标记价、IV、Greeks 在原 30 秒时效门槛内，预算不超过 120。真实公开批量标记请求也完成验证：HTTP 200、完整响应、1,560 行、约 2.265 秒，见 `public-bulk-mark-check.json`。接口可省略 symbol，标记响应权重为 5，核对于[币安官方公开行情文档](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-options/api/rest-api/market-data)。

## 部署后实测

核对服务完整命令行后重启后台，重新加载前端；钱包模板与构建产物同步更新。`live/report.json` 和 `live/frames.jsonl` 为部署后的 120 秒观测，前 30 秒预热：45 组、180 个合约样本，关键字段时效、本机读取、关注续约及实际卖 Put 引擎全部通过；`allGatesPassed=true`。

真实 Chrome 复测确认：手工数量为空时拦截；切回自动数量后错误消失、禁用手工字段且 4 个候选恢复可算；到期日切到无匹配的期权链范围时，显示行数为 0，详情内容也为空；恢复默认、关闭重开后回到自动跟随行情。控制台未捕获 error。页面截图为 `final-page.png`。

后端两阶段审查的具体故障与复测详见上级目录 `backend-second-pass-qa-20261018.md`。

本轮发现的可复现问题已修复；独立复测与两轮全量回归没有再发现未修复的可复现问题。这是已测范围内的结论，不是对所有未来输入、网络、浏览器及长期运行作绝对无 bug 保证。
