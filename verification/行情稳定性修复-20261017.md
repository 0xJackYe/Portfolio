# 行情稳定性修复及验收

日期：2026-10-17，北京时间。更新已加载到当前本机 8766 终端；8765 兼容页面复用同一行情缓存。

## 修复

- 公开 HTTP 响应只有在完整读取、JSON 解析及结构验证通过后才算成功。收到 HTTP 200 后的内容读取超时、连接重置、截断响应分别记录，不再混成笼统的成功状态或网络错误。
- 对暂时性网络中断、部分服务器错误执行最多三次的有上限退避重试。每次实际请求都计入共享权重预算；HTTP 429/418 的冷却影响所有请求线程，冷却期间不会继续发送请求。缓存层遵守客户端传回的冷却时间，即使这次请求已在本地拦截、没有 HTTP 状态码。
- 页面按买卖报价、标记价 / Greeks、指数、24h 统计、目录分别描述状态。标记价失败不会再把仍然有效的盘口统称为“报价缓存”；部分字段新鲜则显示实际覆盖数量。真实断线、陈旧数据和缺失值仍明确显示。
- 保留现有盘口按合约合并的有界队列、连接代次验证、心跳及字段原始时间。未放宽数据过期标准，未把旧数据标成新行情。

## 边界

这段验收只能证明当前运行和观测窗口内的结果。外部 VPN、网络、交易所服务中断仍可能导致降级，程序会自动恢复并保留真实时间。REST 与各条推送本身是异步数据，不能承诺所有字段来自同一毫秒，也不能保证公网永久零中断。
