# 开机启动修复验证

验证日期：2026-10-21。

## 结果

- 开机登录后，当前用户登录任务以普通用户权限启动本地服务，在 Google Chrome 打开期权看板和 ChatGPT。
- 保留 Skyline VPN 原有登录任务及其定义。
- Steam、飞书、Teams 的当前用户启动项已禁用，覆盖 32/64 位 Run 与 StartupApproved，以及 Teams 包启动任务。
- 本地看板先启动，VPN 或外网等待不会阻塞它；重复执行不重复打开两个网页。
- 之前的最高平均日收益、日收益率及排序已存在，并在真实 Chrome 中补验。

## 根因与修复

旧快捷方式存在，但它引用的 C 盘运行目录在真实登录进程中不存在。真实登录进程读取到的 Steam、飞书 Run 项也仍存在，与先前检查环境的结果不同。本次通过当前用户、普通权限的登录任务执行安装，再由同样的原生进程读取文件、注册表和本地服务，避免仅凭检查环境的状态认定安装成功。

初次实际任务测试复现了目录无效错误 0x8007010B，以及去掉工作目录后找不到脚本的退出码 2。完成原生安装后，看板登录任务退出码为 0，服务就绪，Chrome 中两个网页均已打开；再次运行没有新增目标标签。

## 验证证据

- final-tests/report.json：完整回归 1,225 项全部通过，包含 42 项启动器及启动策略离线测试。
- native-verification-final.json：真实登录环境中 23 项注册表检查全部通过，本地服务就绪，VPN 定义与修复前一致；重复安装后无关启动项摘要不变。
- chrome-open-dedup.json：实际 Chrome 页面地址及重复运行前后标签 ID 对照。
- chrome-options.png：实际 Chrome 中已加载的期权报价页面。
- native-install.log：真实登录环境中的安装日志。
- native-startup-backup.json 与 native-policy-backup.json：原始启动设置备份副本；原件保留于实际安装目录。
- workspace-task-origin.json：证明本次修复前看板登录任务不存在；诊断阶段任务捕获另行保留，以便正确恢复原状态。

## 验证范围

本次实际触发了登录任务，检查了 Chrome 网页和本地行情服务，没有执行整机重启或注销。下次真实开机登录仍是最终现场验收。现有运行中的软件不作为是否禁用下次登录自启的判据。VPN 此处负责打开程序，连接行为沿用 VPN 本身。

恢复方式见 windows_startup/开机启动说明.md。
