# DeepSeek 期权筛选验收（2026-10-22）

已更新并启动本机看板：http://127.0.0.1:8766/#options 。普通报价及专注报价均有“AI 选期权”入口；实际 Chrome 页面已联调，默认 V4.1 Flash，可切换 V4 Pro。

## 使用

点击“AI 选期权”，输入明确需求，再点“筛选”。例如：

> 找 2026年10月30日到期的卖 Put，虚值 0%–20%，模拟 0.03 BTC，按每日权利金从高到低选 4 个。

可以继续说“再加上绝对 Delta 不超过 0.25，其他条件保持不变”。已校验的完整条件会随下一轮传递，较早对话裁掉后仍保留原期限与数量。说“重新开始，清除之前全部筛选条件……”可以重置。仅说“安全、稳赚、收益最高”会要求补充可量化标准，不会臆造风险门槛。

结果显示真实合约、到期日、行权价、当前参考买/卖价、模拟数量、整笔平均每日权利金、剩余天数、虚值率、绝对 Delta、标记 IV 与买卖价差。其他 Greeks 可用自然语言设定筛选界限；缺失或过时的参数不会参与该条件的匹配。

“更新报价”按原条件读取新快照重算，不再次调用模型。点“查看当前报价”会重新检查合约是否仍未到期、报价/深度是否有效及条件是否仍满足，然后打开现有盈亏模拟。模拟数量与方向会正确传递。没有符合条件的合约时返回空结果，不放宽条件填充名单。

## 数据和计算

DeepSeek 负责解析筛选需求；本机程序负责匹配真实合约、计算、排序及说明实际执行条件。模型不能指定报价、制造合约、代替本机计算，亦没有下单能力。公开期权行情无需使用交易所账户密钥；不会将交易所密钥、钱包数据或账户持仓发给模型。

解析完成后读取一份完整行情快照计算，保留服务实例、版本、估值时刻、指数与引用标识。日期采用交易所校准时钟和官方到期毫秒数；报价和 Greeks 分别验证时效，盘口认证必须对应同一组报价/数量。

卖出参考买一、买入参考卖一。整笔平均每日权利金 = 权利金单价 × 模拟数量 × 合约乘数 ÷ 实际剩余天数。卖 Put 的现金日权利金率再除以行权价 × 数量 × 乘数；不等同于保证金收益率、盈利期望或每日实际到账。买入方向显示的是权利金支出。金额未扣费，盈亏模拟沿用用户所填费用。

|---|---:|---:|
| V4.1 Flash（deepseek-flash） | 1.414 秒 | 8,814 |

真实 `/models` 已确认两模型可用。依据本次小样本准确率相同、Flash 更快的结果默认 Flash；这不是对长期模型能力或未来延迟的保证。

- Windows 拒绝无效请求时，原来可能因未读请求体引起连接重置、丢失 JSON 错误提示；已加入有限大小及有限等待的清理，并通过相应实际 HTTP 测试。
- Chrome 已验证普通及专注入口、真实筛选、更新报价、当前报价校验、正确的卖 Put 盈亏方向和0.03数量；最终浏览器没有记录脚本警告/错误。截图见 `ai-dashboard.png`、`ai-results.png`、`browser-payoff.png`。

外部交易所、模型服务及本机网络可能中断。现有行情连接沿用自动重连与 REST 降级；AI 超时、错误或限流仅影响筛选任务，已展示结果带时间和快照版本，重试不会伪造最新数据。
