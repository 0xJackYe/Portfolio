# 完整盘口恢复与稳定展示核验

问题：断线重连后价格可能更新，而安静合约尚未重新收到完整盘口数量，工作台因真实深度时间过旧而停算。此前仅验证标记价，不足以证明所有数据组正常。

本次完成：

- 为当前关注合约及默认卖 Put 候选增加独立、有限并发的公开深度和指数恢复。深度通过同一响应原子更新买价、卖价及两边数量；单独价格不能替代深度。检查顺序、并发覆盖、未来时间、排序及交叉盘口。空档保留为真实零流动性。
- WS 断线或换代后撤销旧证明；队列有未处理数据时不能以心跳证明旧盘口仍有效。完整 REST 盘口可在原始接收时间及原有时效阈值内供计算。
- 补齐不依赖全量目录及成交统计成功，使用单飞、退避、每分钟本地预算和共同的 HTTP 限流、429/418 冷却。
- 多个 SSE 客户端共用一次快照构建和 JSON 编码，500 毫秒合并更新；编码在市场锁外，慢客户端独立。原字段时间不被改写。
- 短暂同步时保留同参数、同合约、最多 5 分钟的完整有效参考，明确原时间与非当前可成交状态。当前不可记录为有效试算，CSV 不把历史金额当作当前结果。硬性流动性、风险限制不使用旧结果。
- 来源时间可展开查看，持续刷新保持用户展开状态；暂时失效不改变所选合约和列表顺序。
