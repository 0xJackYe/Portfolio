# 币安期权账户强平风险监控方案

核对日期：2026-10-24。此文件只描述方案与读取验收，不保存用户余额、仓位或密钥。

## 已验证的访问能力

本机加密保存的只读凭据已通过权限核验。以下签名 GET 均成功：

- `/eapi/v1/marginAccount`：调整后权益、维持保证金、初始保证金、可用余额和账户 Greeks。
- `/eapi/v1/position`：实际持仓合约、方向、数量、入场价、标记价和浮动盈亏。
- `/eapi/v1/openOrders`：当前挂单。

`/sapi/v1/portfolio/account` 返回 `-21001`，即未开通统一账户。本次适用普通 Options 账户规则；未来检测到 PM / PM Pro / SPAN 时必须选择另一套计算器，不能复用普通期权阈值。

只读连接代码为 `binance_options_account.py`。它仅允许固定的官方 HTTPS GET，拒绝重定向，校准服务器时间，限制响应大小与查询总时长，剔除交易所错误原文中的敏感信息。完整金融快照只保存在本机 DPAPI 加密文件中。验收 JSON 只记录访问状态、响应码和条数。

## 第一期：先准确显示交易所当前风险

直接使用交易所的 `maintMargin` 与 `adjustedEquity`，显示：

```
维持保证金占用率 = maintMargin / adjustedEquity
到 95% 阈值的保证金余量 = 0.95 × adjustedEquity − maintMargin
```

官方普通 Options 规则：维持保证金大于零时，80% 触发追加保证金提醒，95% 触发强平；调整后权益为负也有强平分支。维持保证金为零但钱包余额为负时，还需检查负余额与符合范围的多头期权价值之比。页面须完整实现这些分支，不能把分母为零显示为“0 风险”。

该“保证金余量”不是固定可承受亏损。价格、波动率变化会同时改变标记价格及维持保证金；也不能从总资产扇形图推导期权抵押品，冷钱包、欧易及币安其他独立钱包的资产不会自动为普通 Options 提供保证金。

按当前规则，调整后权益与通常的净权益不是同一个分母。必须采用 API 的 `adjustedEquity`，避免在维持保证金已经包含空头标记价格时再次从该分母扣除空头市值。

## 第二期：价格 × 波动率 × 时间的压力测试

采集每个持仓的合约乘数、行权价、到期时间、当前标记价格、指数价格与 IV 曲面。维持保证金参数以最新交易所合约信息为准，并记录规则版本。

对普通期权空头，当前公开公式为：

```
Put 虚值额 = max(指数价格 − 行权价, 0)
Call 虚值额 = max(行权价 − 指数价格, 0)

单腿维持保证金 =
  [max(指数价格 × 最低维持保证金率,
       指数价格 × 维持保证金率 − 虚值额)
   × 合约乘数 + 标记价格] × abs(持仓数量)
```

公开常规参数目前为 5% 与 7.5%，但程序应读取合约实际参数并先与账户返回值对账。默认普通 Options 不应假设价差腿获得组合保证金抵扣；合约乘数和数量单位也必须对齐。

建议情景网格（这些是本工具的压力测试设置，不是交易所规则）：

- BTC / ETH 指数价格变动：−30%、−20%、−10%、−5%、0、+5%、+10%、+20%、+30%。
- 隐含波动率变化：−20、0、+10、+20、+40 个百分点；保留期限和行权价间的偏斜。
- 时间：立即、1 天后、7 天后、临近到期；不得跨过真实到期时刻。
- 流动性：按当前买卖差价与额外滑点估算回补成本，分别列出标记风险与实际平仓成本。

每个情景重新定价并重算全账户维持保证金、调整后权益和比例。采用以当前标记价校准的完整期权定价，而非只将 Delta / Gamma / Vega 线性外推到大跌情景。Greeks 用于解释敏感性和核对小幅变化。标价模型、实际波动率曲面和交易所风控标价存在偏差时，结果明确标为估算。

展示热力图与“不同 IV / 时间下触及阈值的价格区间”。当某一情景没有交点或有多个交点时如实显示，不能制造一个永久有效的唯一爆仓价。先不输出“爆仓概率”；概率需要额外的收益分布、跳跃与波动率过程假设和回测。

## 第三期：预警、稳定性和验收

1. 初始以后台固定连接每 3–5 秒刷新账户，公开行情沿用现有实时通道。挂单单独低频核对，并在仓位变化时立即重取；账号、持仓、挂单和行情应保留各自时间戳。
2. 每个来源单独超时和重试；限流遵守退避，不因页面反复打开产生重复轮询。短暂失败保留上次有效快照，并显示其年龄。数据过期时给出“风险数据过期”警报，停止声称风险安全。
3. 报警阈值可配置。可先用 50%、65%、75% 作为提前关注档位，但要标为用户阈值；官方 80% 与 95% 分别显示。报警去重，持续危险时按设定间隔重复，并复用已验证的本地 WAV 声音。
4. 验收覆盖：空账户、纯多头、裸卖 Put / Call、多腿不同到期日、挂单、数量单位、IV 跳升、到期结算、负余额、分母为零、标价缺失、账户切换、断网、429、时间误差及旧快照。零冲击必须复现交易所的当前保证金指标；有未解释差额时停止输出可靠等级，展示对账差额。
5. 本阶段不添加交易或自动减仓。风险读数反映快照与估算，不承诺在价格跳空或断网时赶在交易所强平之前。
