# BTC 全仓保证金卖 Put 测算

查询时间：2026-10-18 00:10（北京时间）。指数价81,401.97130435 USDT。10月30日16:00到期，剩余12.65936434天；不是精确15天。

本次按用户最新要求，将1,000 USDT全部视为可用保证金，估计能开出的最大数量。这里不再采用此前足额现金担保的0.01 BTC仓位限制。只做公开数据计算，没有访问签名账户接口或下单。

前提：普通USDT期权Long/Short账户，已开通卖开权限；没有已有持仓、挂单或其他资金占用；成交价采用查询时买一价；手续费按公开FAQ估算。实际账户权限、风险限额、可卖数量仍须以币安订单预览为准。

## 保证金和数量

S为指数价，K为行权价，M为期权标记价，P为订单报价，q为数量。本次合约乘数为1，实际LOT_SIZE步长为0.01。

```text
OTM = max(S - K, 0)
B = max(0.10 * S, 0.15 * S - OTM)
单张开仓费 = min(0.00024 * S, 0.10 * P)
订单初始保证金 = [max(0, B + M - P) + 单张开仓费] * q
持仓初始保证金 = (B + M) * q
```

对65,000档，P=65，M=69.582，单张开仓费=6.5：

- 每1 BTC数量的下单初始保证金约8,151.27913 USDT。
- 0.12 BTC需要约978.15350 USDT。
- 0.13 BTC需要约1,059.66629 USDT，超出1,000。
- 因此公式估计最大数量为0.12 BTC，并非已核实的账户可下单数量。

订单保证金公式内的−P已经体现权利金抵减，不能再把到账权利金重复加一次以扩大仓位。成交后钱包收款和持仓初始保证金采用各自口径。

## 计算范围与损失

这些数字是本轮权利金收入的折算，不能称为长期平均实际收益。实际损益必须计入赔付、动态保证金、平仓/强平成本，以及以后每轮不同的报价和可用余额。

例如65,000档0.12 BTC若持有至60,000结算：赔付600 USDT，本轮净收款7.02、估算行权费1.08，净损益为−594.06 USDT。实际可能在到期前被部分或全部强平，不能把此到期计算当作保证可持有的结果。毛最大到期赔付为7,800 USDT，不等于1,000账户已核实的损失上限。

官方卖方FAQ与清算程序使用不同OTM符号约定：FAQ的OTM为非负距离并从基础项扣除；清算程序的OTM为非正值并与基础项相加，两者对本次初始保证金公式等价。清算程序的维持保证金还列入0.0019×指数的清算费用准备项；本次最大数量采用FAQ的订单初始保证金公式，没有据此模拟强平路径。
